# Инструкция по публикации сайта (Бесплатно)

## Шаг 1: Загрузка кода на GitHub

(Выполнено! Ваш код уже загружен в репозиторий `royal_motors`)

Если вам нужно будет обновить код в будущем, используйте эти команды:

```bash
git add .
git commit -m "Обновление"
git push
```

## Шаг 2: Публикация на Vercel
1. Зайдите на [Vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New...** -> **Project**.
3. Выберите ваш репозиторий `luxury-motors` и нажмите **Import**.
4. В настройках **Environment Variables** (Переменные окружения) пока ничего не меняйте.
5. Нажмите **Deploy**.
   *Первая сборка может упасть из-за отсутствия базы данных — это нормально.*

## Шаг 3: Подключение Базы Данных (Бесплатно)
1. В панели управления проектом на Vercel перейдите во вкладку **Storage**.
2. Нажмите **Connect Store** -> **Create New** -> **Postgres**.
3. Примите условия, выберите регион (например, Frankfurt - ближе к нам) и нажмите **Create**.
4. Vercel автоматически добавит нужные настройки в ваш проект.
5. Перейдите во вкладку **Deployments**, нажмите на три точки рядом с последним деплоем и выберите **Redeploy**.

## Шаг 4: Настройка структуры базы данных
После успешного деплоя, нам нужно создать таблицы в базе данных.
1. В Vercel перейдите в настройки проекта -> **Settings** -> **Build & Development Settings**.
2. Измените **Build Command** на:
   ```bash
   npx prisma generate && npx prisma db push && next build
   ```
3. Сделайте еще один **Redeploy**.

## Шаг 5: Заполнение справочников
Чтобы в админке появились варианты (Седан, Бензин и т.д.), нужно один раз запустить команду.
1. Откройте ваш опубликованный сайт (ссылка будет вида `luxury-motors.vercel.app`).
2. В адресной строке допишите: `/api/force-seed`
   Пример: `https://luxury-motors.vercel.app/api/force-seed`
3. Вы увидите сообщение `{"success":true,"message":"Seeding completed"}`.

**Готово!** Ваш сайт работает, база данных настроена, картинки сжимаются автоматически.
